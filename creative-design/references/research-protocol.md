# Web research protocol

Use when the library is not enough. Goal: **new techniques and references, not copies**.

## When to search

- The user asks for fresh, current or "what is trending" references.
- No library idea fits the brief.
- A technique needs a modern implementation (shader, view-transition, new CSS feature).
- A candidate needs real assets (public-domain images, textures, fonts).

## How to search

Run several queries in the same turn, from the idea and from the feeling:

- `<idea> CSS effect`, `<idea> SVG filter`, `<idea> WebGL shader`, `<idea> canvas tutorial`
- `<idea> website design inspiration`, `<idea> hero background`
- `<feeling> website background texture` (e.g. "tactile paper website")
- For assets: `public domain <subject> open access museum`, `CC0 texture <name>`

Start with the standard search. Switch to extended only if the results are thin or old.

## Where to look

- **Technique**: Codrops, CSS-Tricks, Smashing Magazine, MDN, web.dev, Shadertoy, CodePen, The Book of Shaders.
- **Inspiration**: Awwwards, Godly, Dribbble, Behance, Siteinspire, Mobbin, Lapa Ninja.
- **Assets (check each license)**: Met Open Access, Art Institute of Chicago, Rijksmuseum, Wikimedia Commons, Unsplash, Poly Haven textures, Openverse.

## What to extract

For each of 3 to 5 references, write down:

1. The **technique** (what it is made of).
2. **Why it works** (the principle: contrast, rhythm, constraint, surprise).
3. The **cost** (performance, legibility, support).
4. The **source URL**, date seen, and **license** if it is code or an asset.

## Rules

- Never reproduce another designer's artwork or paste code with an unclear license. Re-implement from the principle.
- Prefer primary sources (docs, the author's write-up) over listicles.
- Note the date: browser support and trends move.
- Do not put the user's name, project or brand into search queries unless they ask for it.

## After research

Add one entry per useful find to [inbox.md](inbox.md). When an entry is tested and solid, promote it to a file in `backgrounds/` and add a row to [library-index.md](library-index.md).
